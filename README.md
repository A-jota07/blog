# 📝 Blog com Next.js

Este é o repositório do **Blog** que estou desenvolvendo como parte do curso de
**Next.js e desenvolvimento Web moderno** com o professor **Otavio Miranda
(Udemy)**.

O projeto foi criado com **Next.js**, utilizando **React** e **TypeScript**, com
foco em aprendizado, boas práticas e construção de um blog moderno, rápido e
responsivo.

---

## 🚀 Sobre o Projeto

Este blog tem como objetivo principal servir como **projeto de estudo e
portfólio**, onde serão aplicados conceitos importantes do ecossistema React e
Next.js, como:

- Criação de páginas estáticas e dinâmicas
- Organização de componentes
- Uso de rotas no Next.js
- Estilização e layout responsivo
- Boas práticas de desenvolvimento Front-end

O projeto está em constante evolução conforme o avanço no curso.

---

## 📁 Estrutura do Projeto

```
public/
└── Arquivos públicos (imagens, favicon, etc.)

src/
├── app/
│   ├── post/               # Rotas relacionadas aos posts
│   ├── favicon.ico         # Ícone da aplicação
│   ├── globals.css         # Estilos globais
│   ├── layout.tsx          # Layout raiz da aplicação
│   ├── not-found.tsx       # Página 404 customizada
│   └── page.tsx            # Página inicial
│
├── components/             # Componentes reutilizáveis
│   ├── Container/
│   ├── Footer/
│   ├── Header/
│   ├── PostCoverImage/
│   ├── PostDate/
│   ├── PostFeatured/
│   ├── PostHeading/
│   ├── PostsList/
│   ├── PostSummary/
│   ├── SinglePost/
│   └── SpinLoader/
│
├── db/                     # Base de dados/local mock
├── lib/                    # Funções auxiliares e configurações
├── models/                 # Modelos de dados
├── repositories/           # Camada de acesso a dados
└── utils/                  # Funções utilitárias
```
